# Guwahati-Real-Estate-Price-Predictor
# 🏠 Guwahati House Price Prediction

This project is an end-to-end Machine Learning web application that predicts house prices in Guwahati based on user inputs such as area (square feet), number of bedrooms (BHK), bathrooms, and location.

It demonstrates a complete ML workflow, including data preprocessing, model training, backend API development, and frontend integration. The application allows users to enter property details through a clean user interface and instantly receive a price estimate powered by a trained regression model.

## 🚀 Features

* Predict house prices based on area, BHK, bathrooms, and location
* Fast and accurate predictions using a trained ML model
* REST API built using Flask
* Dynamic loading of locations from backend
* Interactive UI with real-time prediction display
* Price output formatted in Indian currency (₹)

## 🛠️ Tech Stack

* Frontend: HTML, CSS, JavaScript, jQuery
* Backend: Python, Flask
* Machine Learning: Scikit-learn, NumPy, Pandas

## ⚙️ How It Works

1. User inputs property details in the web interface
2. Frontend sends a request to the Flask API
3. Backend processes the input and feeds it to the trained model
4. The predicted price is returned and displayed on the UI

## ▶️ Run Locally

1. Clone the repository
2. Install required libraries: flask, numpy, pandas, scikit-learn
3. Run the server using `python server.py`
4. Open the frontend file in a browser
